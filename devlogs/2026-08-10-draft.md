## 2026-08-04

- Nouveau mode Campagne (run roguelite solo façon Slay the Spire) :
  - choix de race avant de lancer une run, deck de départ généré automatiquement (5 cartes-ressource + ~10 cartes Common faible coût de la race choisie)
  - carte de run à embranchements sur 8 paliers (combat / élite / événement / boutique / repos / boss unique en dernier palier), génération par poids avec garanties (aucun nœud orphelin, un repos toujours dispo avant le boss)
  - récompense après un combat gagné : choix de 1 carte parmi 3, tirage pondéré par rareté (mêmes poids que l'ouverture de pack)
  - PV du héros persistants d'un combat à l'autre pendant la run (pas de reset à 30 PV comme en partie rapide), soin partiel aux nœuds repos
  - défaite en cours de run = fin de run immédiate + récompense de consolation en monnaie molle proportionnelle à la progression
  - adversaires pilotés par l'IA existante (`AISystem`), désormais paramétrable (race adverse, difficulté, taille de deck) sans changer le comportement par défaut de la partie rapide
  - 6 nouveaux écrans (`scenes/campaign/`) : sélection de race, carte de run, récompense, repos, événement, fin de run ; nouveau bouton "Campagne" dans le menu principal (verrouillé tant que le tutoriel obligatoire n'est pas terminé)
  - 27 nouveaux tests GUT (génération de carte, filtres CardLibrary par race/rareté, deck de départ, tirage de récompense, paramétrage AISystem, événements, récompense de consolation) — suite complète toujours verte (562 tests)
  - simplifications assumées pour cette v1 (documentées dans TODO.md) : pas de sauvegarde de run entre sessions, pas de monnaie de run séparée pour la boutique, pas de reliques

- Refonte complète du mode Campagne (v1 ci-dessus abandonnée le même jour) suite à l'ajout de `CAMPAIGN.md` (document de design plus abouti) :
  - run **sans fin** : plus de deck/pioche/mana, le plateau se construit par 5 choix de carte au lancement puis par les récompenses ; carte de run générée par fenêtre glissante (jamais un graphe illimité stocké), boss récurrent tous les 10 paliers (plus une fin de run, un jalon)
  - nouveau moteur de combat **auto-battler tour par tour** (`CampaignBattle.tscn`/`.gd`) : scène dédiée légère (11 systèmes réutilisés vs 30+ dans `Battle.gd`), plus de main/mana/pose de carte — le joueur choisit librement quelle carte attaque quelle cible ; CHARGE (bonus d'attaque répétable) implémenté localement à la campagne sans toucher au moteur partagé
  - scaling de la difficulté : Normal x1,5 tous les 10 paliers, Élite/Boss x1,5 par victoire de ce type (compteurs séparés), rareté des adversaires croissante par tranche de paliers
  - or de run + Boutique (achat/amélioration/soin/retrait), Reliques (cartes Enchantement/Rituel obtenues via nœud dédié ou boutique, jamais via la récompense de combat classique)
  - sauvegarde de run locale (`user://`) avant chaque combat (adversaire figé) et après chaque victoire (récompense figée) ; proposition Reprendre/Nouvelle run au lancement du mode
  - `Battle.gd`/`AISystem.gd` entièrement revenus à leur état d'avant la campagne (le combat classique ne sert plus jamais à la campagne)
  - 38 tests GUT au total sur `scripts/campaign/` (carte par fenêtre glissante, construction de plateau, or, reliques, sauvegarde...), suite complète verte (565 tests) ; combat auto-battler et écrans validés par smoke tests headless bout-en-bout (victoire, défaite, sauvegarde/rechargement)
  - points ouverts explicitement laissés par `CAMPAIGN.md` et hypothèses prises documentées dans `TODO.md` (P7)
