# Brouillons de devlog hebdomadaire

Ce dossier contient des notes brutes, non mises en forme, accumulées au fil des sessions de travail pour préparer le devlog public du lundi.

- Un fichier par semaine : `YYYY-MM-DD-draft.md`, où la date est celle du **prochain lundi** de publication.
- Chaque session qui modifie du code ajoute une entrée en fin de fichier (voir format dans `CLAUDE.md`, section « Devlog hebdomadaire »).
- Le lundi, une fois le vrai devlog écrit à partir de ces notes, le fichier est déplacé dans `devlogs/archive/` (ou supprimé si le contenu est repris ailleurs) et un nouveau draft est créé pour la semaine suivante.
